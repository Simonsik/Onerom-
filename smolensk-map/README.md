# Карта Смоленска — Python

## Запуск

Нужен Python 3.9 или новее. Из папки проекта:

```sh
python3 app.py
```

Откройте **http://localhost:8000**. Установка пакетов не нужна: сервер, SQLite и чтение XLSX используют стандартную библиотеку Python. Интернет нужен для Leaflet, тайлов OpenStreetMap и автомобильных маршрутов OSRM.

Другой порт: `python3 app.py --port 8080`. По умолчанию сервер доступен только на этом компьютере. Остановка — Ctrl+C.

## Как устроено

- `app.py` — Python HTTP-сервер, API статистики и маршрутизации, SQLite.
- `data/import_xlsx.py` — нормализация Excel: CSV внутри первой выборки и даты Excel во второй.
- `data/*.xlsx` — исходные таблицы.
- `data/traffic.sqlite3` — автоматически создаваемое хранилище. При запуске импорт обновляется одной транзакцией; повторный запуск не удваивает записи.
- `index.html`, `style.css`, `script.js` — браузерный интерфейс и Leaflet. JavaScript отвечает за взаимодействие с картой; данные и подсчёты поступают из Python.
- `tests/test_app.py` — проверки импорта, интервалов, API, повторного запуска и ошибок маршрутизации.

Сервер отдаёт только файлы интерфейса из разрешённого списка; исходные Excel и база недоступны через HTTP. Сервер рассчитан на локальную работу, без авторизации и production-развёртывания.

## Возможности

18 детекторов, переключение выборок, число проездов и машин за выбранный интервал. Границы фильтра включаются с точностью до минуты; интервал задаётся внутри одного дня. В первой выборке 602 проезда и 127 машин, во второй — 1313 проездов и 200 машин. Исторические наблюдения относятся к 15.10.2025; часовой пояс в исходниках не указан. Подробности — в [DATA_REPORT.md](DATA_REPORT.md).

Выбор точек А и Б, перетаскивание, обмен и сброс. Python запрашивает автомобильные маршруты OSRM. Можно выбирать альтернативы на карте и в панели. По умолчанию выбирается самый короткий **среди возвращённых вариантов**: глобально кратчайший путь по расстоянию не гарантируется. Время расчётное, без текущих пробок. Альтернативы доступны не для всех направлений. Публичный сервер OSRM может быть недоступен.

Загрузка JSON дорог и камер остаётся браузерной: данные действуют до обновления страницы. Формат:

```json
{
  "demo": false,
  "roads": [
    {"name": "Участок дороги", "level": "jam", "coordinates": [[54.7826, 32.035], [54.7826, 32.0453]]}
  ],
  "cameras": [
    {"name": "Камера", "coordinates": [54.7826, 32.0453]}
  ]
}
```

Координаты: **широта, долгота**. Уровни: `free` — зелёный, `busy` — жёлтый, `jam` — красный. Для окраски по дороге нужна полная геометрия участка; двух точек недостаточно для повторения изгибов. Цветные участки не влияют на расчёт маршрута. В предоставленных таблицах геометрии дорог нет, количество проездов не доказывает наличие пробки.

## API

- `GET /api/bootstrap` — детекторы, выборки и замечания импорта.
- `GET /api/detectors?dataset=0&from=07:00&to=09:00` — счётчики проездов; выборки 0 и 1.
- `GET /api/route?points=32.035,54.7826;32.055,54.7826` — маршруты OSRM (здесь координаты: долгота, широта).

Проверки:

```sh
python3 -m unittest discover -s tests -v
```

Миграция сохраняет текущие возможности проекта. Поиск машины, матрица переходов, аналитика аномалий и полный отчёт из документа задания ещё не реализованы.
