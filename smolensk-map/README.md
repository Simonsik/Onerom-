# Карта Смоленска — Python

## Запуск

Нужен Python 3.9 или новее. Из папки проекта:

```sh
python3 app.py
```

Откройте **http://localhost:8000**. Установка пакетов не нужна: сервер, SQLite и чтение XLSX используют стандартную библиотеку Python. Интернет нужен для Leaflet, тайлов OpenStreetMap и автомобильных маршрутов OSRM.

Другой порт: `python3 app.py --port 8080`. По умолчанию сервер доступен только на этом компьютере. Остановка — Ctrl+C.

После изменения файлов достаточно обновить страницу. HTML, CSS и `client.py` сервер читает заново при каждом запросе и отдаёт без кеширования. При изменении серверного Python-кода или исходных XLSX сервер автоматически перезапускается (проверка каждые 0,5 секунды). При синтаксической ошибке продолжает работать со старым кодом до следующего сохранения. Отключить автоперезапуск: `python3 app.py --no-reload`.

## Параллельная разработка

Распределение файлов между интерфейсом и расчётом маршрутов, контракт API и порядок объединения веток: [ROUTE_API.md](ROUTE_API.md). Отрисовка маршрутов вынесена в `route_view.py`; будущие панорамы развиваются там.

## Как устроено

- `app.py` — Python HTTP-сервер, API статистики и маршрутизации, SQLite.
- `traffic.py` — привязка камер к вариантам маршрутов и оценка задержек по историческим скоростям.
- `data/import_xlsx.py` — нормализация Excel: CSV внутри первой выборки и даты Excel во второй.
- `data/*.xlsx` — исходные таблицы.
- `data/traffic.sqlite3` — автоматически создаваемое хранилище. При запуске импорт обновляется одной транзакцией; повторный запуск не удваивает записи.
- `client.py` — управление картой, маршрутами, фильтрами и импортом JSON на Python в браузере через Brython 3.13.2.
- `index.html`, `style.css` — разметка и оформление. Brython и Leaflet загружаются с CDN; Leaflet отвечает за отрисовку карты. Для загрузки Brython нужен интернет. Открывайте страницу через сервер, а не как локальный HTML-файл.
- `tests/test_app.py` — проверки импорта, интервалов, API, повторного запуска и ошибок маршрутизации.

Сервер отдаёт только файлы интерфейса из разрешённого списка; исходные Excel и база недоступны через HTTP. Сервер рассчитан на локальную работу, без авторизации и production-развёртывания.

## Возможности

18 детекторов. Исходные данные восстановлены: выборка 1 — 602 проезда / 127 машин, выборка 2 — 1313 / 200. Исторические наблюдения за 15.10.2025.

Выбор точек А и Б, перетаскивание, обмен и сброс. Python запрашивает маршрут и до трёх альтернатив OSRM; сервис может вернуть меньше. Все полученные варианты оцениваются по времени с учётом камер, выбирается минимальная оценка. Выбранный маршрут синий, альтернативы фиолетовые. Изменение выборки или времени автоматически повторяет сравнение. Публичный сервер OSRM может быть недоступен.

### Оценка загруженности маршрута

Единый порог для всех камер: от 20 проездов за выбранный интервал — условный затор, коэффициент задержки минимум 3. Скоростная оценка также учитывается. Это пользовательское правило модели, не измерение пробки.

Все варианты с замедлением показываются красными; лучший по оценке времени имеет синий контур. Красные участки альтернатив остаются видны при выборе объезда. Карта вмещает все полученные варианты.

На карту передаются максимум два пути: кратчайший по расстоянию из полученных от OSRM и одна отличающаяся альтернатива: более быстрый объезд либо, при заторе, лучший найденный вариант для сравнения без выигрыша времени. Кратчайший путь с замедлением показан красным, более быстрый объезд выбирается автоматически; в карточке объезда указана экономия времени. Дополнительный поиск объездов выполняется вокруг затора на кратчайшем пути. Дополнительные кандидаты с возвратом в пройденные вершины, обратным проходом по тем же отрезкам или отличающимися концами отбрасываются. Геометрический фильтр сокращает тупиковые заезды, но не заменяет полноценную проверку дорожных ограничений.

Если лучший исходный путь содержит замедление, сервер дополнительно проверяет до четырёх объездов через промежуточные точки по сторонам загруженного участка (800 и 1600 м). Геометрические дубликаты и точки дальше 300 м от дороги отбрасываются. Запросы выполняются с паузой; поиск может занять до 90 секунд. Проверяются только конечные кандидаты: отсутствие найденного объезда не доказывает, что его нет в дорожной сети. Исходный путь сохраняется даже при сбое дополнительных запросов. Маршрут через промежуточную точку может включать лишние манёвры; он оценивается как отдельный вариант по общей длине и времени.

Камеры ищутся в пределах 35 м от геометрии каждого варианта. Между последовательными камерами выделяются участки, повторяющие изгибы маршрута. Это приблизительная привязка: исходники не содержат направления камеры и идентификатора дороги; рядом может быть параллельная дорога. Скорость на всём участке предполагается по двум граничным камерам, а не измеряется по времени проезда одной машины.

Для каждой камеры рассчитывается медиана скорости за выбранный интервал. Базой служит 85-й процентиль двадцати самых быстрых положительных измерений этой камеры в выбранной выборке. Нужны минимум три измерения у каждой граничной камеры; участки длиннее 3 км не оцениваются. База относительная: постоянное замедление на протяжении всей выборки может остаться незамеченным.

Коэффициент задержки — среднее отношений базовой скорости к скорости интервала на обеих границах, от 1 до 10. Он увеличивает долю времени OSRM, пропорциональную длине участка. Зелёный: относительная скорость от 70% базы; красный: ниже 70%. При скорости ниже 40% красная линия толще (10 пикселей вместо 8). Цветные участки рисуются поверх линии выбранного маршрута. Это эвристическая оценка, требующая проверки на реальных временах поездок.

Неизвестные участки серые пунктирные и сохраняют базовое время OSRM. В панели показаны камеры, число измерений, покрытие маршрута данными и оценка задержки. Отсутствие наблюдений не означает свободную дорогу; вариант с малым покрытием может оказаться оптимистично оценённым.

Используются исторические записи за 15.10.2025, не текущие пробки. Алгоритм сравнивает конечный набор возвращённых вариантов и заканчивает выбор после оценки каждого. Глобальный оптимум по всей дорожной сети не гарантируется; для него нужен собственный дорожный граф с весами времени и проверенной привязкой камер.

Загрузка JSON дорог и камер остаётся браузерной: данные действуют до обновления страницы. Формат:

```json
{
  "demo": false,
  "roads": [
    {"name": "Участок дороги", "level": "jam", "coordinates": [[54.7826, 32.035], [54.7826, 32.0453]]}
  ],
  "cameras": [
    {"name": "Камера", "coordinates": [54.7826, 32.0453]}
  ]
}
```

Координаты: **широта, долгота**. Уровни: `free` — зелёный, `busy` — жёлтый, `jam` — красный. Для окраски по дороге нужна полная геометрия участка; двух точек недостаточно для повторения изгибов. Цветные участки не влияют на расчёт маршрута. В предоставленных таблицах геометрии дорог нет, количество проездов не доказывает наличие пробки.

## API

При ошибке TLS в системном Python запрос маршрута повторяется через `curl` (на macOS он предустановлен). Проверка HTTPS-сертификатов остаётся включённой. Если оба способа не сработают, причина записывается в терминал сервера.

- `GET /api/bootstrap` — детекторы, выборки и замечания импорта.
- `GET /api/detectors?dataset=0&from=07:00&to=09:00` — счётчики проездов; выборки 0 и 1.
- `GET /api/route?points=32.035,54.7826;32.055,54.7826&dataset=0&from=07:00&to=09:00` — варианты OSRM в порядке возрастания оценки времени; `traffic` содержит камеры, участки, покрытие и задержку. Координаты: долгота, широта. Без фильтров используется выборка 0 и весь день.

Проверки:

```sh
python3 -m unittest discover -s tests -v
```

Миграция сохраняет текущие возможности проекта. Поиск машины, матрица переходов, аналитика аномалий и полный отчёт из документа задания ещё не реализованы.

#коммит
Если маршрут проходит только через одну камеру с достаточными наблюдениями, её скорость применяется локально в пределах 150 м в каждую сторону. Эта приблизительная зона не является измеренной длиной пробки. При заторе найденная отличающаяся альтернатива показывается и без выигрыша времени, с подписью «медленнее»; автоматически выбирается только более быстрый объезд.
